🌸 更新日志

v3.0 2026-02-25
  • 架构重构：工作流升级为五步标准化流程（Step1−5），将原始文件保存、表头解析、填充前验证、填充模板、填充后验证分离为独立阶段
  • Step1：内存中保存原始文件的 ArrayBuffer 只读副本（rawFileBuffer），确保验证阶段始终使用未经任何处理的原始数据
  • Step2：建立 rawSrcColMap、rawSrcRows、rawHeaders 命名体系，明确区分原始数据与工作副本；蒲公英模式将 3 级表头拼接键存入 rawHeaders
  • Step3（新增）：填充前验证——对所有 mapped 字段进行字段一致性验证；任何 mapped 字段在数据源中未找到则立即中止并报错（提示联系管理员更新映射表）； blank/not_found 字段在数据源中出现则警告并继续；将聚光广告单日日期验证并入此阶段
  • Step5（重构）：引入 verifyType 智能推断水山，支持 date / percent / number / integer / text 五种验证规则；日期字段支持序列号与字符串互转比对；百分比字段支持小数与百分比字符串互转；小数精度截断以警告形式通过；整数字段必须 100% 一致
  • 验证报告 UI 重构：统一展示 Step3 验证结果（区块1）与 Step5 验证结果（区块2），错误（红）与警告（黄）分色展示；区块3 显示汇总统计（总行数、错误数、警告数）
  • 每条验证记录新增「类型」列，显示字段的 verifyType 推断结果，方便排查验证规则是否正确

使用说明

① 选择数据类型：选择与数据源对应的类型（蒲公英 / 聚光广告）

② 上传数据源：点击上传区或拖拽文件，支持 .xlsx / .xls / .csv

③ 开始映射：点击"开始映射匹配"，系统自动完成解析与字段匹配

④ 查看日志：切换至"执行日志"标签页，可查看每步详细过程与异常信息

⑤ 下载结果：匹配完成后点击下载，获得填充好的 Excel 模板文件
